Check-in

Press the doorbell, then hold your phone 30–50 cm (about one forearm) from the camera, screen facing the lens. Hold still for 2–3 seconds.

The doorbell press tells the camera to look for your code for about 12 seconds. Turn screen brightness all the way up. The code changes every 15 seconds. If the camera can't read it, the backup code is read instead.
